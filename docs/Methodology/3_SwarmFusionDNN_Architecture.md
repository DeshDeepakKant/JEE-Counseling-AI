# Methodology: SwarmFusionDNN Architecture

Deep Learning models suffer from variance stemming from random weight initialization and noisy data. To increase stability, predictions can be fused using Ensemble Learning.

## The Weighted Average Ensemble Approach

**SwarmFusionDNN** proposes a **Particle Swarm Optimization (PSO)-based Weighted Average Ensemble**. Instead of simple aggregation like voting or traditional stacking, it integrates four modified base models (MobileNet, DenseNet121, MobileNetV2, Xception) dynamically using weights.

### The Problem with Simple Weighting
Traditionally, optimal model weights must be guessed, derived through exhaustive trial-and-error grid searches, or estimated heuristically. This process is time-consuming and often yields suboptimal ensembles that fail to penalize underperforming predictors properly.

### SwarmFusionDNN Process
1. Base models are trained independently with the ConvMixer block added to their heads.
2. Individual predictions $p_i$ are generated by each trained base model on the validation/test set.
3. Instead of flat averaging, an **optimization algorithm (PSO)** computes specific weights $w_i$ constrained between [0, 1].
4. The final ensemble prediction $Y_{pred}$ is a weighted sum:
   $$Y_{pred} = \sum_{i=1}^{n} w_i \cdot p_i$$

### Why Weighting Matters?
By introducing strict weights, SwarmFusionDNN rewards stronger models by amplifying their predictions, while simultaneously penalizing weaker ones. As weights are refined, the ensemble achieves a synergy that heavily outperforms even the best-performing individual model in the group.
